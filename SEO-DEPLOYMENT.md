# Oakline SEO deployment

1. Upload all files in this folder to the GitHub repository root.
2. Commit and push to the branch used by Cloudflare Pages.
3. Wait for the Cloudflare deployment to finish.
4. Verify these URLs:
   - https://oaklinediagnostics.com/sitemap.xml
   - https://oaklinediagnostics.com/robots.txt
   - https://oaklinediagnostics.com/check-engine-light-diagnostics.html
   - https://oaklinediagnostics.com/electrical-diagnostics.html
   - https://oaklinediagnostics.com/no-start-diagnostics.html
   - https://oaklinediagnostics.com/battery-charging-diagnostics.html
   - https://oaklinediagnostics.com/service-areas.html
5. In Google Search Console, submit `sitemap.xml`.
6. Use URL Inspection to request indexing for the home page and each new service page.

Do not change the CNAME file.
